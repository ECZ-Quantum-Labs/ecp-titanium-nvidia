# ECP Titanium (NVIDIA Infrastructure Integration)

Enterprise-grade ephemeral communication protocol and execution layer integrated with NVIDIA Cloud Infrastructure and NIM Microservices.

## Key Features
- **NVIDIA NIM Cloud Integration:** Direct execution via `nvidia/nemotron-3.5-lightning-30b-a3b`.
- **Signed Deletion Receipts:** Cryptographic verification of payload nullification.
- **Low-Latency Benchmarking:** Real-time round-trip execution latency tracking.
